# Tactiekbord

Voetbal-tactiekbord: sleep spelers en de bal, kies een opstelling (11-tal of 8-tal), teken loopacties, passes en dribbels, en sla spelsituaties op.

## Online zetten met GitHub Pages
1. Maak een nieuwe repo, bijvoorbeeld `tactiekbord`.
2. Upload alle bestanden uit deze map (index.html, manifest.webmanifest en de drie png's).
3. Ga naar **Settings → Pages**, kies bij *Branch* `main` en map `/ (root)`, en klik **Save**.
4. Na een minuutje staat de app op `https://<jouw-gebruikersnaam>.github.io/tactiekbord/`.

## Op de iPhone als app
Open de link in Safari → deelknop → **Zet op beginscherm**.

Opgeslagen situaties blijven op het toestel zelf bewaard.
